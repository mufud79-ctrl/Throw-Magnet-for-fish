# Bending game: session prompts

One session per family. Each prompt plans every class in that family with a full moveset (M1, Z, X, C, V, F,
movement, passive) and its own mechanic and matter. Start every session with:

> Read `.claude/skills/roblox-anime-vfx/prompts/bending/_shared.md`, then follow
> `.claude/skills/roblox-anime-vfx/prompts/bending/<family>.md` exactly, one class at a time, waiting for my
> approval on each move (send MP4s and strips with SendUserFile). Don't upload anything.

| Order | Prompt | Classes | Family mechanic |
|---|---|---|---|
| 1 | `fire.md` | Firebending, Lightning, Redirection, Combustion, Dragon Fire | Heat (builds on hits, drains when you back off) |
| 2 | `water.md` | Waterbending, Ice, Healing, Plantbending, Bloodbending (Outlaw), Spirit Purification | Carried water supply |
| 3 | `earth.md` | Earthbending, Metalbending, Sandbending, Lavabending, Seismic Sense | Props persist in the world |
| 4 | `air.md` | Airbending, Flight, Spiritual Projection, Suffocation (Outlaw move) | Momentum |
| 5 | `nonbenders.md` | Chi-blocker, Weapon Master, Engineer | Counters to bending |
| 6 | `avatar.md` | The Avatar (after the four families) | Element switching + Avatar State |

Fire goes first because the Dragon fruit's fire matter already exists.
Design source of truth: `.claude/skills/bending-game-design/` (lore, systems).
