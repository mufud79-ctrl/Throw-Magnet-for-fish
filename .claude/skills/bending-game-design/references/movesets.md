# Movesets

The full per-class moveset plans (M1, Z, X, C, V, F, movement, passive, lead shape per move, family mechanic, matter)
live in the session prompts, one per family:
`.claude/skills/roblox-anime-vfx/prompts/bending/` -> `README.md` (order), `_shared.md` (house rules), `fire.md`,
`water.md`, `earth.md`, `air.md`, `nonbenders.md`, `avatar.md`.

Rule: every class has its own mechanic and its own lead shapes. A class that reuses another class's moves in a new
colour is a failed class. When you change a class, edit its prompt (single source of truth).
